# MentorMind AI — Tutor Demo Flow (< 4 minutes)

Every step feels like an AI tutor guiding the learner — not an analytics dashboard.

## Flow overview

```
Welcome (Home)
  → Today's Mission
  → Lesson
  → Assessment
  → AI Analysis overlay
  → Mentor Feedback
  → Updated Learning Plan
  → Continue Learning (Home)
```

---

## Setup (20 seconds)

| Step | Click | Screen |
|------|-------|--------|
| 1 | **Create My Learning Plan** | Onboarding |
| 2 | **Quick start with AWS defaults** | AI analyzing overlay (~3s) |
| 3 | Auto-redirect | **Home** — Mentor Card (no analytics) |

**Alternate:** Landing → **Start live demo** → Home with demo-ready learner.

---

## Act 1 — First learning session (90 seconds)

| Step | Click | What happens |
|------|-------|----------------|
| 4 | Read Mentor Card | Goal · Why · Duration · Expected outcome |
| 5 | **Start Learning** | Lesson card (concepts + diagram placeholder + takeaway) |
| 6 | **Continue to Assessment** | VPC check-in quiz |
| 7 | **Submit 42% result** | AI analysis overlay (~3s) |
| 8 | Read **AI reasoning summary** → **Continue** | Signal · Twin · Decision · Benefit (goal-linked) |
| 9 | Auto | **Mentor Feedback** — reassurance + weakness explained |
| 9 | **See updated learning plan** | What / why / goal impact + injected tasks |
| 10 | **Continue Learning** | Home — new today's mission |

---

## Act 2 — Mastery recovery (75 seconds)

| Step | Click | What happens |
|------|-------|----------------|
| 11 | **Start Learning** | Lesson (review) |
| 12 | **Continue to Assessment** | VPC quiz |
| 13 | **Submit 95% result** | Mastery analysis overlay |
| 14 | Auto | **Mentor Feedback** — congratulations + mastery explained |
| 15 | **See updated learning plan** | Accelerated plan, next lesson unlocked |
| 16 | **Continue Learning** | Home |

---

## Presenter principles

1. **Never start on metrics** — the Mentor Card is the product.
2. **Follow the tutor flow** — Home → Learn → Assess → Feedback → Plan → Home.
3. **Let the mentor speak** — overlays and feedback pages tell the adaptation story.
4. **Recovery:** Sidebar → Recovery panel (`/demo`) if needed.

**Total clicks:** ~14 for the full loop including both quiz submissions.
